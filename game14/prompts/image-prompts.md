# 「人気者になろう」画像生成プロンプト集（ChatGPT 用）

ゲームの絵を **ChatGPT（画像生成）** で作るための指示文です。
**コツ：1回の生成で「1枚のシート」に全部描かせ → あとで 1つずつ切り出す**（絵柄が そろい、回数も へります）。

## 共通ルール（どのシートにも最初に貼る）

```
【共通ルール】
- 1枚の画像の中に、同じ大きさのマスで格子状にならべて描いてください（列数・行数は各シートの指示どおり）。
- 各マスの間には、はっきりした余白（約4%）を入れ、絵が となりのマスに はみ出さないように。
- 背景は「ベタ塗りの単色（#00FF66 の明るい緑）」。影や グラデーションも つけない。切り抜きやすくするため。
  （ただし「背景シート」は 背景そのものを 描くので 単色にしない。）
- 文字・ロゴ・ウォーターマーク・サインは 入れない（ゲーム内で 文字は別に 重ねます）。
- 絵柄：明るく カラフルな 「アイドル育成ゲーム」風。ネオンの ピンク・シアン・ゴールドを アクセントに。
- 登場人物は すべて 大人（20歳以上）の 見た目。お酒・たばこ・パチンコの場面は 「雰囲気」だけ。
  未成年に 見える人物を 描かない。リアルな 実在人物・有名キャラ・既存ブランドに 似せない（オリジナルのみ）。
- 虫（昆虫・クモ・ムカデ など）は 一切 描かない。背景の 小物・模様・装飾にも 入れない。
- 出力：PNG（透過は不要。緑背景のまま）で OK。あとで 切り抜く。
```

## 作ったあとの 手順（共通）

1. ChatGPT に「共通ルール」＋ 各シートの指示を貼って 生成。
2. 絵柄が ずれたら「同じ絵柄で、2行目だけ やり直して」のように 部分だけ 直してもらう。
3. 出来た シートを 保存し、画像編集ソフト（または `tools` の切り出しスクリプト）で マスごとに 切り出す。
4. 緑（#00FF66）を 透明に（「色域指定で 透過」）→ **PNG** か **WebP（品質85）** で 書き出す。
5. 置き場所の 目安：`game14/img/`（例：`char_mika.webp`）。ファイル名は 各シートの 表のとおり。
6. 2D（イラスト）も 3D風（ぷっくりした CG 風）も 試せる：各シートの 末尾の「3D版の言い換え」を 追加で 貼る。
