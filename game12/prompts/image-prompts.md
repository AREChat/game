# 「AREUSO」画像生成プロンプト集（ChatGPT 用）

3D アクション「AREUSO」（ノイズの大軍を斬りひらく）の **イラスト・アイコン・背景** を、ChatGPT（画像生成）で作るための指示文です。
**コツ：1回の生成で「1枚のシート」に全部描かせ → あとで 1つずつ切り出す**（絵柄が そろい、回数も へります）。
いまの ゲームは 画像ファイルなしでも 動きます（3D は プログラムで 描画）。ここで 作った 絵は **タイトル・武将えらび・リザルト・OGP** などに 使えます。

## 共通ルール（どのシートにも最初に貼る）

```
【共通ルール】
- 1枚の画像の中に、同じ大きさの マスで 格子状に ならべて 描いてください（列数・行数は 各シートの 指示どおり）。
- 各マスの 間には はっきりした 余白（約4%）を 入れ、絵が となりの マスに はみ出さないように。
- 背景は「ベタ塗りの 単色（#00FF66 の 明るい 緑）」。影や グラデーションは つけない（切り抜き用）。
  （「ステージ背景」「キービジュアル」だけは 背景そのものを 描くので 単色に しない。）
- 文字・ロゴ・ウォーターマーク・サインは 入れない（文字は ゲーム内で 重ねます）。
- 絵柄：ネオンが 光る「未来の 戦国」ふうの 3D アクション。紺・紫の 夜空に、ピンク・シアン・ゴールドの 光。
  キャラは かっこよく、動きの ある ポーズ。暴力的すぎる 表現（血・ざんこく な 描写）は なし。
- 敵「ノイズ」は 「ざらざらした 光の かたまりで できた 人形」。ノイズの ような ドット欠け・ひび・四角い 光の かけらで 表す。
  生き物（動物・昆虫・クモ など）の 形には 似せない。
- 虫（昆虫・クモ・ムカデ など）は 一切 描かない。背景の 小物・模様・装飾・エフェクトにも 入れない。
  触角・たくさんの 足・羽の ような 形も 使わない。
- 実在の キャラ・作品・ブランド・武将ゲームの 既存キャラに 似せない（オリジナルのみ）。
- 出力：PNG（緑背景のまま）で OK。あとで 切り抜いて 透明に します。
```

## 作ったあとの 手順

1. ChatGPT に「共通ルール」＋ 各シートの 指示を 貼って 生成。
2. 絵柄が ずれたら「同じ 絵柄で、◯行目だけ やり直して」と 部分的に 直してもらう。
3. シートを 保存 → 画像編集ソフトで マスごとに 切り出す。
4. 緑（#00FF66）を 透明に（色域指定）→ **PNG** か **WebP（品質85）** で 書き出す。
5. 置き場所の 目安：`game12/img/`。ファイル名は 各表の とおり。
6. 2D（イラスト）でも、3D風（CG の フィギュアふう）でも OK：各シートの 末尾に「3D版の言い換え」を 足して 貼る。
