# 「ARE 前代未聞ラボ」画像生成プロンプト集（ChatGPT 用）

対象：**ことばクラフト**／**ふたごの世界**／**ルール・ルーレット**（3本ぜんぶ）。
**1回の生成で「1枚のシート」に全部描かせ → あとで 1つずつ切り出す** 方式です（絵柄が そろい、生成回数も へります）。

## 共通ルール（どのシートにも最初に貼る）

```
【共通ルール】
- 1枚の画像の中に、同じ大きさの マスで 格子状に ならべて 描いてください（列数・行数は 各シートの 指示どおり）。
- 各マスの 間には はっきりした 余白（約4%）を 入れ、絵が となりの マスに はみ出さないように。
- 背景は「ベタ塗りの 単色（#00FF66 の 明るい 緑）」。影や グラデーションは つけない（切り抜き用）。
  （「背景シート」「キービジュアル」だけは 背景そのものを 描くので 単色に しない。）
- 文字・ロゴ・ウォーターマーク・サインは 入れない（文字は ゲーム内で 重ねます）。
- 絵柄：あかるく ポップな「実験室（ラボ）」風。パステル＋ビビッドな アクセント、ぷっくりした フチどり。
- 実在の キャラ・ブランド・ゲームに 似せない（オリジナルのみ）。
- 虫（昆虫・クモ・ムカデ など）は 一切 描かない。小さな 模様・背景の 飾りにも 入れない。
- 出力：PNG（緑背景のまま）で OK。あとで 切り抜いて 透明に します。
```

## 作ったあとの 手順

1. ChatGPT に「共通ルール」＋ 各シートの 指示を 貼って 生成。
2. 絵柄が ずれたら「同じ 絵柄で、◯行目だけ やり直して」と 部分的に 直してもらう。
3. シートを 保存 → 画像編集ソフトで マスごとに 切り出す。
4. 緑（#00FF66）を 透明に（色域指定）→ **PNG** か **WebP（品質85）** で 書き出す。
5. 置き場所の 目安：`game11/img/`。ファイル名は 各表の とおり。
6. 2D（フラットな イラスト）でも、3D風（ぷっくりした CG・粘土風）でも OK：各シートに「3D版」を 足して 貼る。
