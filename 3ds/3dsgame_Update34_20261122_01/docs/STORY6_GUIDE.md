# 第6章「三つのあかり」分岐ガイド（ネタバレあり）

第5章のボス（ダッシュ王）を たおすと、洞くつで 星の精 **ルミナ** が あらわれ、3つの「とい」を なげかけます。
こたえは **「はい」「いいえ」「わからない」** の 3つだけ。えらびかたで 物語が まったく ちがう 道に 分かれます。
（ぜんぶで 3つの とい × 3 = 27とおりの ルート、エンディングは 9つ）

## 分かれ道（ひとつめの とい）

> その 力を、すべての 人の ために ささげると、誓えますか？

| こたえ | 道 | ようす |
|---|---|---|
| **はい** | A: 星守（ほしもり）の道 | 光を みんなに わける。町を まもる 戦い。仲間が ふえる |
| **いいえ** | B: 星砕き（ほしくだき）の道 | 力を ひとりじめ。洞くつが くずれ、ガイが はなれて いく かも しれない |
| **わからない** | C: 旅人の道 | 推理で かげの 正体を さぐる。かげの 世界へ いく |

## A: 星守の道

1. 町ミルフィが かげに おそわれる。**ダッシュ王を なかまに する？**（ふたつめの とい）
   - はい → ダッシュ王が なかまに（モンスター牧場）。さいごの 戦いで いっしょに たたかう
   - いいえ → 屋根の 上から 町を まもる
   - わからない → かげから こっそり ついて くる
2. 戦い → **2Dアクション「星のぼり」**（走る・ジャンプ・バネ・ダッシュ）で 星の ほこらへ
3. かげの 王 **ヤミ** との 戦い。さいごの とい: **この 子を、ゆるしますか？**
   - はい → エンディング1「みんなの ほしあかり」
   - いいえ → エンディング2「ひとり ねむる ほし」
   - わからない → エンディング3「きえない かげ」

## B: 星砕きの道

1. 結晶が くだけ、**2Dアクション「くずれる洞くつ」**（画面が すすむ！にげろ）
2. 星の かけらが 体に すいこまれ、**ぜんいんの ちからが 大きく あがる**。ガイが おこる。**ガイを 引きとめる？**（ふたつめの とい）
   - はい → ガイは のこる
   - いいえ / わからない → **ガイが パーティを はなれる**
3. かげの 王 ヤミ（あなたの さみしさから 生まれた かげ）との 戦い。さいごの とい: **かけらを 世界へ かえしますか？**
   - はい → エンディング4「かけらの かえる ばしょ」（ちからは もとに もどり、ガイも もどって くる）
   - いいえ → エンディング5「ひとりの ほしぐも」（ちからを 持った まま）
   - わからない → エンディング6「はんぶんの ひかり」

## C: 旅人の道

1. 学び舎で 調べもの。**ひらめきタイム ×2**（かげの 正体・ダッシュ王の なぞ）
2. **2Dアクション「かげと光」**（Xボタンで 光の 世界 ⇄ かげの 世界を きりかえ）
3. かげの 子 ヤミと 話す。**ヤミの 言葉を ぜんぶ 信じる？**（ふたつめの とい）
   - はい → 信じる（ヤミが 心を ひらく）
   - いいえ / わからない → 信じきれない（ヤミが あばれる）
4. 戦い。さいごの とい: **このふたつを、もういちど ひとつに もどしますか？**
   - はい → エンディング7「ふたつの ほしあかり」
   - いいえ → エンディング8「はなれて よりそう ほし」
   - わからない → エンディング9「つづく たび」

## おわったあと

- ミルフィの 町の 人たちが、**えらんだ 道に ちなんだ おはなし**を して くれます。
- ミルフィの **「星の 記録」**（広場の まん中）で、べつの 道を もういちど えらびなおせます。見た エンディングの きろくは のこります。
- 選択画面と エンディング画面に **「あかりの いろ」**（金＝はい / 青＝いいえ / 白＝わからない の 数）が 出ます。
- ミルフィの **アスレチック場**で、3つの 2Dアクションを いつでも あそべます。

## 2Dアクションの あそびかた

- 十字キー: 左右に あるく　**A**: ジャンプ（おすほど たかく）　**B**: ダッシュ（空中でも）　**X**: 光 ⇄ かげ（「かげと光」の 面）
- トゲや 穴に おちても、その場の チェックポイントから やりなおし。ゲームオーバーは ありません。
- **3回 ミス**すると **Yボタンで その面を とばせます**（ごほうびは 出ません）。
- 星の かけらを あつめると、クリアの ごほうびの ゴールドが ふえます。

## 声・アニメ・えんしゅつ

- 第5章の おわり〜第6章の せりふには **ボイス**（合成音声）が ついています。Xメニューの ショートカットに「ボイスオン/オフ」を わりあてると、すぐ きりかえられます。ボイスが ない せりふは 「ぴこぴこ」音が 鳴ります。
- 文字は 1文字ずつ あらわれます。**A** で ぜんぶ 出し、もう一度 **A** で すすみます。**R** おしつづけで はやおくり。
- 画面の ゆれ・フラッシュ・ブラインドの ワイプ・ダメージの 数字・紙ふぶき・タイトルの 星の またたき など。
