# ストーリーがわかりにくい、という声への対応(Update11)

## わかりにくい理由(想定)
1. いま何をすればいいか(目的)が画面に出ていない。
2. 章と章の間のつながり(なぜ引っ越すのか、誰が味方か)の説明が足りない。
3. 登場人物が多く、誰がどんな人か覚えにくい。
4. 場面が変わる時に、場所と時間の説明がない。

## 直し方(ゲームに入れる案・次回以降 game.c へ)
- **「いまの目的」を画面の上に1行**: 例「保健室で先生の話を聞こう」。章ごとに ch?data.h に目的文を持たせる。
- **「あらすじ」メニュー**: Xメニューに「あらすじ」を追加。これまでの章を1〜2行ずつ表示。
- **登場人物リスト**: 会ったことがある人だけ、名前と一言説明を表示。
- **場面の最初に「場所・時間」をナレーションで1行**(例「星あかり祭りの夜。ひなた村の広場」)。
- 長い話は短い文に分け、1画面1〜2文にする(やさしい言葉で)。

## あらすじ(これまで・やさしい言葉)
- **第1章 はじまりの広場**: 星が降る夜に生まれた主人公は、幼なじみのセラと出会う。空とぶ舟を直し、山賊を追い返し、みつば園でコマの取り合いを「5分だけ使って次は交代」のルールで解決。
- **第2章 学び舎の事件**: 新しい学び舎で、先生が縛られている事件が起きる。相棒ガイと推理して、校長の企みを暴く。
- **第3章 勤勉の像の謎**: なくされそうな像のわけを、みんなの前で推理して明かす。そのあと、暗い山里クロモリへ引っ越す。
- **第4章 家族の危機**: 嵐で家がこわれ、母が家出。主人公は手がかりを集めて、母を説得する。新しい学び舎では、みんなの名前を覚える作戦で友だちになる。
- **第5章 首の病と最下位**(Update11で下準備): 夜ふかしの勉強で首が回らなくなり、試験は最下位。お祭りの料理で おなかも こわす。ミオと一緒に「ねる時間を守って、毎日ひとつずつ」の勉強法に変え、立ち直る。
- **この先**: ミオとの特訓 → 差出人不明の挑戦状 → 入学試験 → 謎解き研究部 → 手紙の送り主を追う → ゼノの罠 → 井戸と塔 → 最終章「星あかりの夜」。
