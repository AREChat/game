# ChatGPT用：全キャラ・建物・地面のドット絵プロンプト

主人公は別ファイル「ChatGPT用_主人公4方向画像プロンプト.md」を使います。
このファイルは、**主人公いがいの登場人物（16人）・建物（8軒）・地面（11種）**のプロンプトです。
どれも、先に「共通ルール」をChatGPTに貼ってから、続けて個別のプロンプトを貼ってください（同じ会話のなかで続けると、絵のふんいきがそろいます）。

今のゲームでの絵の大きさは、人=16×16、建物=48×48、地面=16×16 です。
作り直しでは、**ちょうど2倍（人=32×32、建物=96×96、地面=32×32）**にします。あとでClaudeが、コードの大きさの設定を合わせます。

---

## 0. 共通ルール（最初に貼る）

```
これから、3DSの2Dファンタジー RPG「ほしあかり英雄譚」(星と夜空がテーマ、やさしい冒険もの)に使う、ドット絵の素材を何枚か作ってもらいます。
すべてに共通するルールです。覚えておいてください。

- 完全オリジナルのデザイン。有名な作品やキャラクターに似せない
- ドット絵。にじませない(アンチエイリアスなし)。拡大してもピクセルがくっきり
- 輪郭は黒ではなく、濃い紺色(#202040)の1ピクセル線
- 影は1段階だけ(右下に影、左上にハイライト)
- 1つの絵につき色は16色以内。やわらかい、明るめの配色
- 背景は透明(できなければ、真っ白の単色)
- 見下ろし型(ゼルダの伝説:神々のトライフォースのような、少し斜め上から見た角度)
- 人物は3頭身のデフォルメ。まるい顔。かっこかわいい
- 出力は PNG と、8倍に拡大した見やすいプレビュー、使った色の一覧(16進数)
```

## 3. 地面・タイル（11種・各32×32）

地面のタイルは、**となりに並べたときに、つなぎ目が目立たない**ようにします。

```
次の地面タイルを、32×32で作ってください。上下左右にならべても、つなぎ目が目立たないように(シームレスに)。
1. ゆか(学び舎の中の、ベージュの木のゆか)
2. しばふ(明るい緑の草。小さな草のもよう)
3. みち(茶色い土の道。小石が少し)
4. かべ(灰色の石のかべ。レンガのもよう)
5. がれき(くずれた石と木片。灰色と茶色)
6. 出口(光る青い魔法のマーク。床に描かれた星の紋章)
7. 調査スポット(金色の「？」または星がうかぶ、光る地面。目立つように)
8. 水(青い水。小さな波のもよう)
9. 花(しばふの上に、赤・黄・白の小さな花)
10. 駅のホーム(灰色の石のホームの端。黄色い線)
11. 線路(茶色の枕木と、銀色のレール)

横8列で、上の順番に並べた1枚のPNGにしてください(11枚なので、2行目に3枚)。全体で256×64。
```

## 4. できたあとにすること

1. ChatGPTからもらったPNGを、Googleドライブの「3dsゲーム」フォルダに置く（名前は、`chars_new.png`、`buildings_new.png`、`tiles_new.png` など、わかる名前）。
2. Claudeに「素材を差し替えて」と伝える。
3. Claudeが、大きさの設定（今は人16・建物48・地面16）を、2倍(32・96・32)に直して、テストも更新します。
4. 差し替えたあとは、GitHub(AREChat/game の 3ds/)にも自動で上がります。

## 5. うまくいかないとき

- 色がちがう・顔がへん: 「(この人)の髪の色を〇〇に直して。ほかはそのまま」と、1か所ずつ頼む。
- ドットがにじむ: 「アンチエイリアスなし。ピクセルがくっきりした、ドット絵にして」と、もう一度頼む。
- 大きさがちがう: 「正確に32×32ピクセルで。ちがう場合は、最近傍補間で縮小して」と頼む。
- どうしても1枚にまとめられない: 1人ずつ作ってもらい、Claudeがまとめる。
