# ChatGPT用：主人公の4方向ドット絵プロンプト（かっこよく作り直し版）

今の絵は 16×16 でとても小さく、顔が大きな丸だけなので、ださく見えます。
作り直しでは **32×32**（3DSの画面でもきれいに見える大きさ）にして、体のバランスをよくし、影もつけます。

## プロンプト(貼りつけ用)

```
3DSの2Dゲーム（ファンタジーRPG、星と夜空がテーマ）に使う、主人公のドット絵キャラクターシートを作ってください。
ポケモン／ドラゴンクエストのような、かっこかわいい雰囲気にしたいです。ただし、既存のキャラには似せず、完全オリジナルにしてください。

【キャラクター】
- 14歳ぐらいの少年（またはどちらにも見える中性的な子）。元気で、ちょっとだけ勇ましい
- 3頭身（頭が大きすぎない。手足がちゃんと見える）
- ふわっとした茶色の髪（前髪とあほ毛が少しあるシルエット）
- 額に、赤いバンダナ。真ん中に小さな金色の星。後ろに結び目としっぽが少し出る
- 青いジャケット（えりと、そでのふち取りは明るい水色）、ベルト、茶色のブーツ、紺色のズボン
- 小さな星のペンダント

【作ってほしい絵】
同じキャラクターを、4方向で。各方向「立ち」「歩き左足」「歩き右足」の3コマ。
1. 前向き（正面）
2. 後ろ向き（背中。髪とバンダナの結び目が見える。顔は見えない）
3. 左向き（完全な横向き。顔は左。鼻と目が横から見える）
4. 右向き（完全な横向き。顔は右。左向きの単なる反転ではなく、バンダナのしっぽがきちんと反対側になびく）

【ならべ方】
- 1枚のPNG、4行 × 3列（行: 前, 後ろ, 左, 右 / 列: 立ち, 歩き左足, 歩き右足）
- 1コマは 32×32 ピクセル、全体で 96×128
- 背景は透明（なければ真っ白の単色。あとで透明にします）
- ドット絵として、にじませない（アンチエイリアスなし、ピクセルがくっきり）
- 輪郭は、黒ではなく濃い紺色の1ピクセル線
- 色は16色以内。影は1段階だけ（右下に影、左上にハイライト）
- 4方向で、頭の大きさ・体の高さ・足もとの位置（地面に立つ線）をそろえる
- 歩きのコマは、足と腕の動きだけをかえる。頭の高さは1ピクセルだけ上下させる

【出してほしいもの】
1. 上の96×128のPNG
2. そのPNGを、見やすいように8倍に拡大したプレビュー画像
3. 使った色（16進数コード）の一覧
```

## 使い方

1. 上のプロンプトをChatGPTに貼って、できたPNGをもらう。
2. 気に入らなければ「もっと明るい色で」「髪をもう少し長く」などと、続けて直してもらう。
3. 気に入ったものを `hero_sheet.png` という名前で、Googleドライブの「3dsゲーム」フォルダに置く。
4. Claudeに「主人公の絵を差し替えて」と伝える。

## Claude側でやること（差し替え時）

今のコードは、16×16・2コマ(立ち／歩き)で、番号は `前1,前2,後ろ1,後ろ2,左1,左2,右1,右2` です（`dir*2+step`、dir: 前=0,後ろ=1,左=2,右=3）。
32×32・3コマにするには、画像を読む大きさ(`SPR_PERSON_PX`)と、コマの選び方(`spr_hero_frame`)、表示の拡大率を直す必要があります。
差し替えのときに、Claudeがここを直し、テストも更新します。

## かんたんな別案

32×32が難しければ、「16×16・2コマ(横8コマ×縦1行)」のままで、次の一文をプロンプトに足してください。
「1コマは16×16、横8コマ×縦1行。左から 前1,前2,後ろ1,後ろ2,左1,左2,右1,右2。」
この場合、コードはそのまま使えます。
